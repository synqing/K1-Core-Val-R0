## 1. System Power Architecture Summary
The system power tree branches from a single protected 5V USB/External entry point into dedicated subsystems:
- **5V_PROTECTED / 5V_SYS**: Main 5V trunk monitored by an INA226 high-side Kelvin-sensed current shunt (RSH1).
- **+5V_LED (Left & Right)**: Dedicated 0.95 A envelope branch with eFuse protection.
- **+3V3_SYS**: Regulated 3.3V system rail generated by low-noise synchronous buck converter (TPS62913, 3A rated).
- **+3V3_MIC**: Switched, low-noise filtered 3.3V rail for the IM69D130 MEMS microphone.
- **+1.15V_CORE**: Regulated core supply for MIMXRT1062 generated by internal DC-DC converter from 3.3V.
- **+5V_NFC**: Filtered 5V supply for the ST25R3916B RF transmitter stage.

## 3. Headroom & Safety Margin Analysis [PROJECTED]
- **5V Trunk Capacity**: 2.35 A rating vs. 1.58 A peak load $\implies$ **32.8% Headroom (0.77 A margin)**.
- **3.3V Buck Capacity**: 3.00 A rating vs. 0.63 A peak load $\implies$ **79.0% Headroom (2.37 A margin)**.
- **5V LED Branch Capacity**: 0.95 A eFuse clamp vs. 0.95 A peak load $\implies$ **Hardware-enforced limit**.
