**The class is assigned per entry, not per tier.** A few Tier 1 entries carry a
DATASHEET-DERIVED class — the netlist confirms the pin is floating, but only a vendor document
says it must not be — and a few later entries carry NETLIST-CONFIRMED because the 14:58 DRC
names them outright. The tier is the execution order; the class is the evidence.

**Ordering rule applied.** Deletions of debris precede additions in the same area
(RQ-001 before RQ-028). Anything that changes a net's membership precedes anything that audits
it. **No-Connect reversals precede every wiring transaction on the same pins** — because an NC
flag is an assertion that the open state is correct, and writing a wire to a pin the sheet has
already certified as unused leaves two contradictory records.

**Severity is a tiebreaker, not the sort key.** A P0 that only a datasheet can see is still
ordered after a P2 that the netlister names, because the netlist-confirmed item is the one whose
evidence survives the live drift.
